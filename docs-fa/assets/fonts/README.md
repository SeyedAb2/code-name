# فونت‌ها

هر دو فونت **لوکال** هستند. هیچ درخواستی به گوگل یا هیچ CDN دیگری زده نمی‌شود و
همه‌چیز بدون اینترنت کار می‌کند.

| فایل | فونت | نقش | حجم |
|---|---|---|---|
| `Vazirmatn-Variable.woff2` | Vazirmatn | تمام متن فارسی و همهٔ عددهای نمایشی | ۱۰۹ KB |
| `JetBrainsMono-var.ttf` | JetBrains Mono | کد، ترمینال، مسیر فایل | ۲۹۶ KB |

هر دو فونت **متغیر** (variable) هستند: یک فایل، همهٔ وزن‌ها از ۱۰۰ تا ۹۰۰. برای
همین به‌جای چهار فایل جداگانه فقط یکی داریم.

## چرا عددها با وزیرمتن نمایش داده می‌شوند

`JetBrains Mono` رقم فارسی (`۰۱۲۳۴۵۶۷۸۹`) ندارد. اگر عددهای فارسی را با آن
نمایش بدهی، مرورگر مجبور می‌شود برای هر رقم به یک فونت دیگر برگردد و نتیجه
به‌هم‌ریخته می‌شود.

برای همین در `theme.css` یک توکن جدا تعریف شده:

```css
--num: var(--fa);                      /* حالت فارسی → وزیرمتن */
:root[data-lang="en"]{ --num: var(--mono); }  /* حالت انگلیسی → مونو */
```

و روی هر جایی که عدد نمایشی دارد اعمال شده است: `.fact b`، `.hero-stats b`،
درصدهای پیشرفت، شمارهٔ فصل‌ها، شمارهٔ بخش‌های فهرست و `ol.ranked`.

**کد همیشه مونو می‌ماند** — چه فارسی چه انگلیسی. چون داخل بلوک کد فقط رقم
انگلیسی داریم و هم‌عرض بودن ستون‌ها آنجا مهم است.

## جایگزین کردن با فونت دیگر (مثلاً ایران‌یکان)

فقط دو کار لازم است:

1. فایل `woff2` را در همین پوشه بگذار.
2. در `theme.css` بلوک `@font-face` مربوط به `Vazirmatn` و مقدار توکن `--fa` را
   عوض کن. هیچ‌جای دیگری دست نزن — همهٔ صفحه‌ها از همین یک توکن می‌خوانند.

```css
--fa:'IRANYekanX','Vazirmatn',system-ui,'Segoe UI',Tahoma,sans-serif;
```
