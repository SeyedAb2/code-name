دواپس و CI/CD

DevOps & CI/CD

این مسیر دربارهٔ ابزار نیست، دربارهٔ فاصلهٔ بین «کد نوشتم» و «کاربر دارد ازش استفاده می‌کند» است. هر فصل یک تکه از آن فاصله را خودکار می‌کند.

This track is not about tools; it is about the gap between “I wrote the code” and “a user is using it”. Each chapter automates one piece of that gap.
