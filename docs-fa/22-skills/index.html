مهارت‌های مهندس نرم‌افزار

Software engineering skills

هیچ‌کس به‌خاطر ندانستن یک تابع اخراج نمی‌شود. آدم‌ها به‌خاطر تخمین‌های غلط، کدی که کسی نمی‌تواند نگهداری کند، و نتوانستن توضیح کارشان گیر می‌کنند. این مسیر دربارهٔ همان چیزهاست.

Nobody gets fired for not knowing a function. People get stuck on bad estimates, on code nobody can maintain, and on being unable to explain their work. This track is about those things.

Chapters build on each other; the order is deliberate. Every track ends with three final projects: easy, medium and hard.
