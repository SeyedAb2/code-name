ASP.NET Core

این مسیر فرض می‌کند ‎C#‎ را می‌دانی و می‌خواهی با آن سرویس وب بنویسی — سرویسی که تست دارد، امن است، و روی یک سرور لینوکسی پشت Nginx کار می‌کند.
