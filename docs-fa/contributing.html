Contributing guide

این سند دقیقاً می‌گوید چطور یک فصل یا یک دورهٔ کامل به کدنامه اضافه کنی. هیچ دانش قبلی از این پروژه لازم نیست؛ فقط HTML مقدماتی.

This page tells you exactly how to add a chapter or a whole track to Codenameh. No prior knowledge of the project is needed — just basic HTML.

قانون‌های غیرقابل مذاکرهThe non-negotiable rules

۱ — بدون ترجمه1 — No translation

حق نداری متن هیچ کتاب یا مستند تجاری را ترجمه یا بازتولید کنی. همه‌چیز باید با ادبیات، ساختار و مثال‌های خودت نوشته شود. سرفصل‌ها راهنمای پوشش موضوعی‌اند، نه دستور ترجمه.

You may not translate or reproduce text from any book or commercial documentation. Everything must be written in your own words, structure and examples. An outline is a guide to coverage, not an instruction to translate.

۲ — دستورها را واقعاً اجرا کن2 — Actually run the commands

هر دستوری که می‌نویسی را باید خودت اجرا کرده باشی و خروجی‌ای که نشان می‌دهی باید واقعی باشد، نه حدس.

Every command you publish must be one you have run, and every output you show must be real, not guessed.

۳ — هیچ تمرینی بدون پاسخ3 — No exercise without a solution

«این را خودتان امتحان کنید» ممنوع است. پاسخ باید بگوید چرا، نه فقط چه.

“Try it yourself” is banned. A solution must explain why, not only what.

معماری در سه دقیقهThe architecture in three minutes

سه چیز را بفهمی، همه‌چیز را فهمیده‌ای.

Understand three things and you understand all of it.

assets/courses.js

تنها منبع حقیقت. فهرست همهٔ دوره‌ها و فصل‌ها اینجاست. صفحهٔ اصلی، خانهٔ مسیرها، ستون کناری، جستجو و پیشرفت — همه از همین می‌خوانند.

The single source of truth. Every track and chapter lives here. The home page, track pages, sidebar, search and progress all read from it.

assets/theme.css

کل سیستم طراحی. رنگ‌ها از توکن‌های :root می‌آیند و در دارک‌مود خودکار عوض می‌شوند. هیچ رنگی را مستقیم ننویس.

The whole design system. Colours come from :root tokens and swap automatically in dark mode. Never hard-code a colour.

assets/app.js

رفتار مشترک: تم، زبان، کپی، فهرست خودکار، پیشرفت، جستجو، کشوی موبایل. معمولاً دست‌نخورده می‌ماند.

Shared behaviour: theme, language, copy, auto TOC, progress, search, mobile drawer. You usually leave it alone.

نتیجه: برای اضافه کردن یک دوره، هیچ HTMLای دست‌نویس نمی‌کنی. فقط مانیفست را ویرایش می‌کنی و سازنده را اجرا می‌کنی.

The upshot: adding a track requires writing no HTML at all. You edit the manifest and run the generator.

قالب مانیفستThe manifest format

هر فصل یک آرایهٔ فشرده است. ترتیب مقادیر ثابت است:

Each chapter is a compact array. The order of values is fixed:

docs-fa/assets/courses.js
["04", "04-dockerfile.html", 0, 12, 60,
 "نوشتن Dockerfile؛ لایه‌ها و کش",
 "هر دستور یک لایه است. ترتیب دستورها یعنی تفاوت بیلد ۲ ثانیه‌ای و ۲ دقیقه‌ای.",
 "Writing a Dockerfile; layers and cache",
 "Every instruction is a layer. Order is the difference between a 2-second and a 2-minute build.",
 "dockerfile layer cache کش لایه"]

اضافه کردن یک فصلAdding a chapter

  1. از الگو کپی بگیرCopy the template

    فصل ۱ داکر الگوی مرجع است؛ هر کامپوننتی که لازم داری آنجا نمونه دارد.

    Docker chapter 1 is the reference template; every component you need is demonstrated there.

    bash
    cp docs-fa/01-docker/ch/01-intro.html docs-fa/01-docker/ch/04-dockerfile.html
  2. صفت‌های ‎<body>‎ را درست کنFix the <body> attributes

    اگر این سه را اشتباه بزنی، ستون کناری و نوار پیشرفت کار نمی‌کنند.

    Get these three wrong and the sidebar and progress bar stop working.

    04-dockerfile.html
    <body data-page="chapter" data-course="01-docker" data-chapter="04">
  3. بخش‌ها را بنویسWrite the sections

    هر بخش یک <section id> با یک <h2>. فهرست کناری خودکار از همین‌ها ساخته می‌شود.

    Each section is a <section id> with an <h2>. The sidebar list is built from these automatically.

  4. دوزبانه بنویسWrite it bilingually

    هر متنی که ترجمه دارد دو بار می‌آید: یکی lang="fa"، یکی lang="en". CSS آن‌که لازم نیست را پنهان می‌کند.

    Any translatable text appears twice: once with lang="fa", once with lang="en". CSS hides the one not in use.

    صفت lang را فقط برای همین کار استفاده کن. برای یک کلمهٔ انگلیسی وسط متن فارسی از <code> استفاده کن — وگرنه در حالت فارسی ناپدید می‌شود.

    Use the lang attribute only for this. For a single English word inside Persian prose use <code> — otherwise it vanishes in Persian mode.

  5. فصل را آماده اعلام کن و بسازMark it ready and build
    bash
    # در courses.js مقدار [2] را از 0 به 1 تغییر بده، بعد:
node tools/build-pages.js

این‌ها حداقل‌اند، نه هدف. فصلی که کمتر از این داشته باشد پذیرفته نمی‌شود.

چک‌لیست قبل از ارسالChecklist before you submit

  • فایل با دابل‌کلیک و بدون اینترنت درست باز می‌شود
  • The file opens correctly by double-click, with no internet
  • در دارک‌مود و لایت‌مود هر دو خوانا است
  • Readable in both dark and light mode
  • در عرض ۳۷۵px به‌هم نمی‌ریزد و کشوی فهرست باز و بسته می‌شود
  • Holds together at 375px and the contents drawer opens and closes
  • سوییچ FA/EN همهٔ متن‌ها را عوض می‌کند و چیزی جا نمی‌ماند
  • The FA/EN switch swaps every string, with nothing left behind
  • هیچ بلوک کدی بدون dir="ltr" نمانده
  • No code block is missing dir="ltr"
  • همهٔ دستورها را واقعاً اجرا کرده‌ای
  • You have actually run every command
  • هر section و هر .ex یک id یکتا دارد
  • Every section and every .ex has a unique id
  • هر تمرین پاسخ کامل دارد و هیچ TODO نمانده
  • Every exercise has a full solution and no TODO remains
  • در کنسول مرورگر خطایی نیست
  • No errors in the browser console

سؤال داری؟

Questions?

اگر مطمئن نیستی فصلی که در نظر داری با روح این مجموعه جور است یا نه، قبل از نوشتن یک issue باز کن و بپرس. بهتر از این است که ده ساعت بنویسی و بعد معلوم شود جایش اینجا نبود.

If you are unsure whether the chapter you have in mind fits, open an issue and ask before you write it. Better than spending ten hours and finding out it did not belong.
