# CodeNames — Linux for Networking — Editorial Pass

این نسخه با فصل اول Git به‌عنوان مرجع صدای نویسنده بازنویسی شده است.

## جهت بازنویسی

- فارسی از حالت documentation و نثر رسمی فاصله گرفته و به لحن یک مدرس باتجربه نزدیک شده که کنار دانشجو نشسته و قدم‌به‌قدم با او جلو می‌رود.
- فعل‌های رسمی تا جای ممکن به فرم روزمره تبدیل شده‌اند: «می‌شود → می‌شه»، «می‌کند → می‌کنه»، «اگر → اگه»، «را → رو»، «می‌تواند → می‌تونه» و ... .
- شروع هر ۱۷ فصل دوباره نوشته شده تا فصل از یک موقعیت واقعی، درد یا سؤال شروع شود؛ نه از تعریف رسمی.
- توضیح‌های میانی و پایانی هم یک پاس جدا برای لحن محاوره‌ای خورده‌اند تا کیفیت فقط در ابتدای فصل خوب نباشد.
- واژه‌های انگلیسی غیرضروری کم شده‌اند. اصطلاح‌های فنی واقعی مثل SSH، systemd، unit، firewall، route و commandهای لینوکس فقط جایی مانده‌اند که واقعاً نقش فنی دارند.
- پروژه‌های پایانی حالت مأموریت و تحویل مهندسی خود را حفظ کرده‌اند و لحنشان به همان صدای مدرس نزدیک شده است.

## چیزهایی که عمداً دست نخوردند

- تمام command/outputهای داخل `<pre>` با نسخهٔ Luna یکسان مانده‌اند.
- متن انگلیسی فصل‌ها دست‌نخورده نگه داشته شده است.
- تعداد sectionها، جدول‌ها، detailsها، code blockها و SVGها تغییر نکرده است.
- ساختار HTML و کلاس‌های فعلی پروژه حفظ شده‌اند.

## کنترل فنی نهایی

- ۱۷ فایل HTML بررسی شد.
- محتوای تمام `<pre>`ها با منبع اولیه مقایسه و یکسان تأیید شد.
- تعداد عناصر اصلی HTML در منبع و خروجی مقایسه شد و اختلافی پیدا نشد.
- ۲۴ SVG بررسی شدند و `viewBox` حفظ شده است.
- attributeهای SVG مثل `markerWidth`, `markerHeight`, `refX`, `refY` با case درست حفظ شده‌اند.
- هیچ متن فارسی ناخواسته‌ای وارد بلوک‌های `lang="en"` نشده است.
- یک پاس نهایی از انتهای فصل‌ها به سمت ابتدا انجام شد تا تمرین‌ها، پاسخ‌ها، پروژه و جمع‌بندی خشک‌تر از شروع فصل نشوند.
