بهینه‌سازی query بر پایهٔ evidenceEvidence-based query tuning

`EXPLAIN` نقشهٔ انتخابی optimizer رو نشان می‌ده؛ `EXPLAIN ANALYZE` statement رو اجرا می‌کنه و اندازه‌گیری واقعی می‌ده، پس فقط روی query و دادهٔ امن استفاده‌اش کن. تعداد ردیف تخمینی رو با actual، تعداد loopها، filter و زمان هر iterator مقایسه کن. بعد از تغییر index یا SQL، چند اجرای قابل‌مقایسه بگیر و اثر write/storage رو هم بسنج. cache گرم، دادهٔ کوچک یا بار متفاوت ممکنه نتیجه رو عوض کند. optimizer hint رو آخرین ابزار بدان، نه اولین درمان.

`EXPLAIN` shows the optimizer's chosen plan; `EXPLAIN ANALYZE` executes the statement and reports actual measurements, so use it only with safe queries and data. Compare estimated with actual rows, loops, filtering, and iterator timing. After changing an index or SQL, run comparable trials and measure write/storage impact too. Warm cache, small data, or a different workload can change the result. Treat optimizer hints as a last resort, not the first fix.
