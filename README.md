# کدنامه — Codenameh

**مرجع‌های مهندسی نرم‌افزار، به فارسی.**

مجموعه‌ای از مستندهای آموزشی فارسی — از جنس صفحه‌های راهنمای رسمی
(MDN، Docker Docs، PostgreSQL Manual)، نه وبلاگ‌پست و نه اسلاید.
هدف این است که خواننده‌ای که **هیچ چیز نمی‌داند** بتواند از فصل ۱ شروع کند و
در پایان هر مسیر، کار حرفه‌ای و عملیاتی انجام دهد.

## راه‌اندازی

```bash
git clone https://github.com/SeyedAb2/code-name.git
cd code-name
npm install

npm run dev     # http://localhost:3000
npm run build   # ساخت نسخهٔ نهایی
npm start       # اجرای همان نسخه
```

Node نسخهٔ ۲۰ به بالا لازم است.

## ساختار پروژه

```
src/
  app/            مسیرهای Next (خانه، مسیر، فصل، دسته، رودمپ، علاقه‌مندی‌ها)
  components/     کامپوننت‌های رابط کاربری
  context/        تنظیمات کاربر (زبان و تم) و پیشرفت مطالعه
  lib/            داده و ابزارها؛ roadmaps/ محتوای رودمپ‌هاست
  styles/         توکن‌ها، استایل سراسری و استایل متن فصل‌ها
content/          متن فصل‌ها: content/<مسیر>/<فصل>.html
data/             منبع سرفصل‌ها: courses.js و categories.js
public/           فونت، لوگو و نمایهٔ جستجو
tools/            export-manifest.js و make-logo.js
deploy/           نمونهٔ پیکربندی Nginx
```

### دو منبع حقیقت، و نه بیشتر

* **سرفصل‌ها** فقط در `data/courses.js` نوشته می‌شوند. بعد از هر تغییر:

  ```bash
  npm run manifest    # src/lib/courses.data.ts و public/search-index.json را می‌سازد
  ```

* **متن هر فصل** فقط در `content/<مسیر>/<فصل>.html` است. صفحهٔ فصل، فهرست
  مطالب و شمارش تمرین‌ها خودشان از روی همین فایل ساخته می‌شوند.

## استقرار

```bash
docker compose up -d --build     # http://localhost:8080
```

ایمیج سه‌مرحله‌ای است و نسخهٔ نهایی فقط خروجی `standalone` را روی یک
Node کوچک اجرا می‌کند. برای انتشار روی دامنه، نمونهٔ پیکربندی Nginx در
[`deploy/nginx.conf`](deploy/nginx.conf) هست.
