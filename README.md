# کدنامه — Codenameh

**مرجع‌های مهندسی نرم‌افزار، به فارسی.**

مجموعه‌ای از مستندهای آموزشی فارسی — از جنس صفحه‌های راهنمای رسمی
(MDN، Docker Docs، PostgreSQL Manual)، نه وبلاگ‌پست و نه اسلاید.
هدف این است که خواننده‌ای که **هیچ چیز نمی‌داند** بتواند از فصل ۱ شروع کند و
در پایان هر مسیر، کار حرفه‌ای و عملیاتی انجام دهد.

## اجرا

### ساده‌ترین راه — بدون هیچ ابزاری

فایل `docs-fa/index.html` را دابل‌کلیک کن. تمام.

بدون سرور، بدون Node، بدون اینترنت. فونت‌ها لوکال‌اند و هیچ درخواستی به بیرون
زده نمی‌شود.

### با داکر

```bash
docker compose up -d --build
```

مرورگر → <http://localhost:8080>

خاموش کردن:

```bash
docker compose down
```

اگر پورت ۸۰۸۰ اشغال بود، در `compose.yml` فقط عدد سمت چپ `"8080:80"` را عوض کن.

### با یک وب‌سرور محلی

```bash
cd docs-fa
python -m http.server 8080
```

## می‌خواهم مشارکت کنم

این پروژه متن‌باز است و بیشترین چیزی که لازم دارد **نوشتن فصل** است.
۴۱۹ فصل هنوز نوشته نشده‌اند.

راهنمای کامل در **[CONTRIBUTING.md](CONTRIBUTING.md)** است، و همان راهنما را
داخل خود پروژه هم می‌توانی بخوانی: `docs-fa/contributing.html`.

خلاصهٔ خیلی کوتاهش:

1. **یک فصل انتخاب کن** که در `courses.js` مقدار `ready` آن `0` است.
2. فایل `docs-fa/<مسیر>/ch/<نام-فایل>.html` را بساز — از
   `docs-fa/01-docker/ch/01-intro.html` به‌عنوان الگو کپی بگیر.
3. محتوا را طبق **[چک‌لیست کیفیت](CONTRIBUTING.md#چک-لیست-قبل-از-ارسال)** بنویس.
4. در `courses.js` آن `0` را `1` کن.
5. `node tools/build-pages.js` را اجرا کن.
6. Pull request بفرست.

اگر نوشتن فصل کامل زیاد است، این‌ها هم کمک بزرگی‌اند:

- تصحیح غلط املایی و نگارشی
- گزارش دستوری که کار نمی‌کند
- ترجمهٔ بخش انگلیسی فصل‌هایی که فقط فارسی دارند
- بهبود نمودارها
- گزارش مشکل نمایش در مرورگر یا اندازهٔ صفحهٔ خاص

## اصول این پروژه

این‌ها سلیقه نیستند؛ قوانینی‌اند که کیفیت را نگه می‌دارند.

**۱. هیچ‌چیز از روی کتاب یا مستند تجاری ترجمه نمی‌شود.**
همه‌چیز با ادبیات، ساختار و مثال‌های خودمان نوشته می‌شود. سرفصل‌ها راهنمای
پوشش موضوعی‌اند، نه دستور ترجمه.

**۲. هر مفهوم دقیقاً چهار سؤال را جواب می‌دهد:**
چیست · چرا (اول درد، بعد ابزار) · چطور (کد واقعی و اجراشدنی) ·
کجا خراب می‌شود (دام‌ها و پیام خطای دقیق).

**۳. کد باید کپی‌پیست‌شدنی باشد.**
بدون `$` ابتدای خط، بدون `...` وسط. هر دستور غیربدیهی، خروجی واقعی‌اش را هم
نشان می‌دهد.

**۴. کامنت داخل کد فارسی است.**
این تفاوت اصلی با مستندات انگلیسی است.

**۵. هیچ ادعای عددی بدون منبع.**
اگر مطمئن نیستی، ننویس. اگر عدد به نسخه بستگی دارد، صریح بگو.

**۶. هیچ تمرینی بدون پاسخ کامل.**
«این را خودتان امتحان کنید» ممنوع است. پاسخ باید بگوید *چرا*، نه فقط *چه*.

**۷. بدون فریم‌ورک، CDN، npm در خروجی، یا build step برای خواننده.**
