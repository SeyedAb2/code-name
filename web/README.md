# کدنامه — اپ Next.js

انتقال سایت ایستای `docs-fa/` به Next.js 16 + TypeScript + SCSS.

## اجرا

```bash
npm install
npm run dev     # توسعه
npm run build   # بیلد تولیدی
```

## ساختار

```
src/
  app/          مسیرها (App Router)
  components/   کامپوننت‌ها، هرکدام با ماژول SCSS خودش
  context/      ترجیحات (تم، زبان) و پیشرفت خواندن
  lib/          داده، نوع‌ها، ذخیره‌سازی، دوزبانگی
  styles/       توکن‌ها، فونت‌ها، پایهٔ سراسری
```

## دادهٔ دوره‌ها

سرفصل‌ها همچنان در `docs-fa/assets/courses.js` نوشته می‌شوند — یک فایل ساده
که ویرایشش آسان است. بعد از هر تغییر:

```bash
node ../tools/export-manifest.js
```

این ابزار `src/lib/courses.data.ts` را می‌سازد. آن فایل را دستی ویرایش نکن.

## نکتهٔ اندازهٔ payload

مانیفست کامل حدود ۷۸۰ کیلوبایت است. کامپوننت‌های کلاینت نباید شیء `Track`
کامل بگیرند، وگرنه Next همهٔ ۱۳۸۹ فصل را در payload سریال می‌کند.
`lib/view.ts` نسخهٔ سبک‌شده می‌سازد — همین کار صفحهٔ اصلی را از ۸۴۴ به
۳۵۲ کیلوبایت رساند.
